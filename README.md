# Jire Orinoco

Landing page de **JIRE ORINOCO, C.A.** — empresa venezolana de procura internacional, servicios de campo, energía y soluciones especializadas para petróleo y gas.

## Características

- 🪟 Diseño **clear glass** (glassmorphism estilo iPhone) sobre paleta verde · amarillo · negro olivo
- 🛢️ Hero animado del campo petrolero (balancines, mechurrio, torre) en SVG
- 🌙 Modo nocturno / claro (recuerda la preferencia y respeta la del sistema)
- 🌐 Bilingüe Español / Inglés (cambio instantáneo, recuerda la elección)
- 📱 Responsive, accesible, sin dependencias ni build
- 🔺 Logo geométrico nuevo y favicon con soporte para temas claro/oscuro
- 🛠️ Secciones de servicios de campo, procura internacional y servicios especializados

## Estructura

- `index.html` — marcado y contenido
- `styles.css` — estilos y tokens de tema claro/oscuro
- `script.js` — tema, idioma (i18n), animaciones y formulario

## Uso

Abre `index.html` en el navegador. O sirve la carpeta localmente:

```bash
python -m http.server 8000
# luego abre http://localhost:8000
```
